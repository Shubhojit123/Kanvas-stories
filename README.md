# Kanvas-stories

Premium wedding and destination photography website for Kanvas Stories, Jodhpur. Built with Next.js 15, Tailwind CSS, TypeScript, and Lucide React.

## Features
- **Modern Responsive Design**: Faithfully recreated from Figma designs.
- **Home & About Pages**: Interactive hero, featured wedding showcases, testimonial carousels, team showcase, and FAQ accordions.
- **Dynamic Navigation**: Auto-hiding navbar on scroll down, subtle glassmorphism on scroll up, and active link indicators.
- **Optimized SEO**: OpenGraph, Twitter cards, JSON-LD Schema markup, dynamic sitemap, and robots.txt.
- **Static Export Ready**: Configured for static site generation (`next export`).

## Getting Started

First, install dependencies:
```bash
npm install
```

Run the development server:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Build for Production
```bash
npm run build
```
